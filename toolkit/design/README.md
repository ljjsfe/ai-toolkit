# design

Adopted, not rewritten: **impeccable** (see `../external.yaml`). It owns visual design taste.
**taste-skill** v2 is listed there as optional, for marketing pages only; install one design
system per project, not both.

This folder holds only what impeccable does not cover. Currently: nothing public.
Personal taste preferences go in `personal.local.md` (not exported).

If a gap in impeccable shows up in real use, add a small skill here that covers exactly that
gap and cross-references impeccable — never a second design system.
